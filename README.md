# Система оформления заказа обуви «Чудо Обувь».   



## Описание



Система предназначена для просмотра каталога обуви, поиска и фильтрации товаров, формирования и управления заказами.



Основные возможности:

- Просмотр каталога и информации о товарах.

- Поиск, фильтрация и сортировка обуви по цене.

- Выбор размера и количества товара.

- Формирование и оформление заказов.

- Автоматический расчёт скидки.

- Управление заказами в зависимости от роли пользователя.



Предусмотрены четыре категории пользователей: неавторизованный пользователь, авторизованный пользователь, менеджер и администратор.



## Установка



Клонируйте репозиторий и перейдите в папку проекта:



```bash

git clone https://github.com/Denzo-10/DemExamen.git

cd DemExamen

```



Настройте подключение к SQL Server в конфигурации проекта и выполните сборку:



```bash

dotnet build

```



## Использование



Для запуска приложения выполните:



```bash

dotnet run

```



Неавторизованный пользователь может просматривать каталог. Авторизованный пользователь может формировать и подтверждать заказы. Менеджер может просматривать, добавлять и удалять заказы, а администратор — дополнительно редактировать их.



## Системные требования



- .NET 10.0.

- SQL Server 18 и доступ к базе данных.

- Операционная система Windows 10 и выше.

- Git для получения исходного кода.



## Контрибьютинг



Изменения вносятся через Git в отдельной ветке. Перед отправкой изменений необходимо проверить работоспособность проекта, создать коммит с описанием изменений и оформить Pull Request.



При разработке необходимо соблюдать единый стиль кода и структуру проекта.
